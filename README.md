# MOONL

Лаунчер Moonshine для установки и обновления игровых сборок **VALM для Valheim** и **CORM для Core Keeper**.

## Установка

[Скачать MOONL 1.9.3.0 — GitHub](https://github.com/MoonshineChips/moonl-releases/releases/download/moonl-files-3effbb58e95e97ceca48/MOONL-Setup.zip) · [Резервная ссылка — Google Drive](https://drive.google.com/uc?export=download&id=1r43vpeYm5zU7_Pqn24Qu89nPbpj4SWkw)

Это стартовый установщик с поддержкой зеркал. Последующие версии устанавливаются через обновление лаунчера.

1. Скачайте архив **MOONL-Setup.zip** по ссылке выше.
2. Распакуйте архив и запустите `MOONL.exe`.
3. Выберите папку лаунчера. MOONL найдёт игры в библиотеках Steam; путь каждой игры можно указать отдельно в настройках.

Для скачивания не нужны аккаунты GitHub или Google. Лаунчер распространяется отдельно от игр; сами игры должны быть установлены у вас.

## Источники обновлений

В MOONL 1.9.3.0 источники используются в порядке **GitHub → Яндекс Диск → Google Drive**. При сетевой ошибке лаунчер пробует следующий источник. Подписи выпусков и SHA256 файлов проверяются перед установкой.

Это отдельный репозиторий распространения MOONL. В нём находятся публичные файлы выпусков, каталоги и изображения. Учётные данные издателя, ключи подписи и личные сохранения сюда не публикуются.

## Для владельца зеркала

MOONL Publisher использует Google Drive только для публикации файлов в отдельной папке MOONL. Подключать свой Google Drive пользователям лаунчера не нужно. [Использование данных Google](PRIVACY.md).
